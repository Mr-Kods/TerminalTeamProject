# 🎓 Найди профессию по интересам в Калининградской области

> **Интеллектуальный веб-сервис профориентации школьников, абитуриентов и студентов Калининградской области на базе искусственного интеллекта (LLM).**  
> Разработано командой **Terminal Team** при поддержке инициативы *«Молодёжь 39»* и АНО *«Цифровое развитие»*.

---

## 🌟 Ключевые возможности сервиса

* 🤖 **ИИ-подбор профессий:** Глубокий анализ интересов, хобби и предпочтений пользователя с генерацией реалистичных рекомендаций (востребованность, зарплатные вилки, специфика региона).
* 🏫 **Каталог учебных заведений:** Автоматический подбор вузов, колледжей и техникумов Калининградской области, контакты приёмных комиссий, бюджетные и платные места.
* 💬 **Интерактивный диалог и история:** Непрерывный контекстный чат с ИИ, автосохранение сессий, инлайн-переименование и удаление диалогов.
* 👤 **Личный кабинет и безопасность:** Управление профилем, защищённое хранение данных, каскадное удаление аккаунтов.
* 🔐 **Восстановление пароля по Email:** Генерация 6-значных криптографических OTP-кодов с отправкой красивых брендированных писем через SMTP.
* 🌓 **Светлая / Тёмная темы и Двуязычность:** Полная адаптация под светлую и тёмную темы, а также русский и английский языки (`RU` / `EN`).
* 📱 **Адаптивный интерфейс:** Идеальное отображение на смартфонах, планшетах и широкоформатных мониторах.

## 🚀 Быстрый старт и локальный запуск

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/Mr-Kods/TerminalTeamProject.git
cd TerminalTeamProject

# Создание виртуального окружения
python -m venv venv

# Активация окружения (Windows PowerShell / CMD):
venv\Scripts\activate
# Для Linux / macOS:
source venv/bin/activate

# Установка библиотек
pip install -r requirements.txt
```

### 2. Настройка переменных окружения (`.env`)
Создайте файл `backend/.env` (или скопируйте `.env.example`):

```env
# Секретный ключ приложения для шифрования сессий и кук
SECRET_KEY=super-secret-key-12345

# Подключение к модели искусственного интеллекта (OpenRouter)
OPENROUTER_API_KEY=ваш_ключ_openrouter_api_key
OPENROUTER_MODEL=google/gemini-2.5-flash

# Порт приложения (8080 для CloudPub или 5000 по умолчанию)
PORT=8080
FLASK_DEBUG=False

# (Опционально) Настройки отправки почты через Яндекс (SMTP):
SMTP_SERVER=smtp.yandex.ru
SMTP_PORT=465
SMTP_USER=ваш_логин@yandex.ru
SMTP_PASSWORD=ваш_пароль_приложения_яндекса
SMTP_USE_SSL=true
SMTP_USE_TLS=false
```

### 3. Запуск веб-сервера
```bash
python backend/run.py
```
Сервер запустится и будет доступен по адресу: **http://127.0.0.1:8080** (или `http://127.0.0.1:5000`).

## 🌐 Публикация в интернет

### Вариант A: Через CloudPub (`clo.exe`) — *Быстрый туннель*
1. В первом окне запустите сервер:
   ```cmd
   python backend/run.py
   ```
2. Во втором окне запустите публикацию:
   ```cmd
   clo.exe publish http 8080
   ```
3. Сервис станет доступен по выданной публичной ссылке: `https://<ваш_поддомен>.cloudpub.ru` *(порт `:443` указывать не нужно)*.

### Вариант B: Через Nginx (Production Reverse Proxy)
В проекте подготовлен готовый файл конфигурации [`nginx.conf`](nginx.conf):
```cmd
# Запуск Nginx на Windows с конфигурацией проекта:
nginx.exe -c C:\Projects\Frontend\nginx.conf
```
* Nginx мгновенно раздаёт статику (HTML, CSS, JS, шрифты, графику);
* Защищает файлы исходного кода (`.py`, `.env`, `.db`, логи);
* Перенаправляет запросы к `/api/` на локальный бэкенд Flask.

## 📧 Настройка отправки почты (Яндекс.Почта / Mail.ru / Gmail)

Для реальной отправки писем с 6-значными кодами восстановления пароля:

### 1. Настройка Яндекс.Почты (за 1 минуту):
1. **Разрешить доступ почтовым программам:**  
   Откройте [mail.yandex.ru/#setup/client](https://mail.yandex.ru/#setup/client) и включите галочки:
   * ✅ *С сервера imap.yandex.ru по протоколу IMAP*
   * ✅ *Пароли приложений и OAuth-токены*
   * Нажмите **«Сохранить изменения»**.
2. **Создать «Пароль приложения»:**  
   Перейдите в [id.yandex.ru](https://id.yandex.ru) → раздел **«Безопасность»** → **«Пароли приложений»** → создать пароль с типом **«Почта»**.
3. Вставьте логин и выданный 16-значный пароль в `.env`.

## 🛠️ Решение частых проблем (Troubleshooting Guide)

### ❓ Проблема 1: Ошибка SMTP `_ssl.c:1064: The handshake operation timed out`
* **Причина:** На компьютере включён VPN или прокси-клиент (FlClashX / Clash / V2Ray в режиме TUN). Почтовые порты (465 и 587) блокируются на VPN-серверах для защиты от спама.
* **Решение:**
  1. Временно отключите VPN на время отправки почты;
  2. Либо добавьте в профиль Clash правило прямого соединения (**DIRECT**) для Яндекса:
     ```yaml
     rules:
       - DOMAIN-SUFFIX,yandex.ru,DIRECT
       - DOMAIN-SUFFIX,ya.ru,DIRECT
       - DOMAIN-SUFFIX,mail.ru,DIRECT
       - DOMAIN-SUFFIX,openrouter.ai,PROXY
       - MATCH,DIRECT
     ```
  *(При возникновении ошибки бэкенд автоматически выведет одноразовый код прямо в консоль сервера, позволяя продолжить тестирование)*.

---

### ❓ Проблема 2: Ошибка SMTP `(535, b'5.7.8 Error: authentication failed: This user does not have access rights to this service')`
* **Причина:** В настройках Яндекс.Почты отключен доступ по протоколу IMAP/SMTP.
* **Решение:** Перейдите по ссылке [https://mail.yandex.ru/#setup/client](https://mail.yandex.ru/#setup/client) и включите галочку *«С сервера imap.yandex.ru по протоколу IMAP»* и *«Пароли приложений»*.

---

### ❓ Проблема 3: Доступность OpenRouter API из РФ
* **Причина:** Провайдер `openrouter.ai` может требовать проксирование из некоторых сетей РФ.
* **Решение:**
  * Использовать правило `DOMAIN-SUFFIX,openrouter.ai,PROXY` в Clash;
  * Либо указать в `.env` адрес любого OpenAI-совместимого шлюза (ProxyAPI, VseGPT, Bothub) или подключить российские модели (GigaChat / YandexGPT).

---

### ❓ Проблема 4: Порт `8080` (или `5000`) уже занят
* **Решение в Windows PowerShell:**
  ```powershell
  # Найти процесс, занимающий порт 8080:
  netstat -ano | findstr :8080
  # Завершить процесс по PID:
  taskkill /PID <номер_PID> /F
  ```
  Или просто измените `PORT=5000` в файле `backend/.env`.

## 🧱 Архитектура и стек технологий (Для защиты проекта)

```
Frontend/
├── backend/                       # Серверная часть приложения
│   ├── app/
│   │   ├── __init__.py            # Фабрика Flask (create_app), LoginManager, CORS
│   │   ├── models.py              # Модели User, ChatSession, PasswordResetCode
│   │   ├── auth.py                # Роуты авторизации, профиля, OTP-восстановления
│   │   ├── routes.py              # Роуты ИИ-рекомендаций, чатов и истории
│   │   └── email_service.py       # Модуль отправки брендированных HTML-писем по SMTP
│   ├── instance/
│   │   └── database.db            # Реляционная база данных SQLite
│   ├── config.py                  # Конфигурация и переменные окружения
│   └── run.py                     # Точка входа для запуска сервера
├── index.html                     # SPA разметка всех экранов и модальных окон
├── script.js                      # Клиентская логика, роутинг, асинхронные запросы, i18n
├── style.css                      # Адаптивная CSS-вёрстка, светлая/тёмная темы
├── nginx.conf                     # Конфигурация обратного прокси-сервера Nginx
├── requirements.txt               # Список зависимостей Python
├── .env.example                   # Шаблон переменных окружения
└── README.md                      # Документация проекта
```

### Стек технологий:
* **Frontend:** HTML5, CSS3 (Flexbox/Grid, Dark Mode), Vanilla JavaScript (ES6+, Async/Await, XSS Sanitization, Markdown Parser).
* **Backend:** Python 3.10+, Flask, Flask-SQLAlchemy (SQLite), Flask-Login, Pydantic v2 (строгая валидация JSON от нейросети), Werkzeug Security (`scrypt` / `pbkdf2`), нативный `smtplib` с брендированными HTML-шаблонами.
* **AI & LLM:** OpenRouter API (Google Gemini 2.5 Flash / Claude 3.5), контекстная память диалога.
* **Безопасность:** Защита от Path Traversal, экранирование XSS, защищённые `HttpOnly` и `SameSite=Lax` cookie, 10-минутные криптографические OTP-токены.
